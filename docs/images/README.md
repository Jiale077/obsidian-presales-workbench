# 配图与截图

## 封面

`hero-jiale-ai-workshop.png` 为本项目新生成的概念插图，采用「Jiale的AI工坊」的视觉方向：暖白 `#F7F3ED`、炭黑 `#282B2D`、珊瑚橙 `#F36B40`、少量青绿 `#4F8A78`，墨线、少量网点和清楚的任务顺序。

使用内置图像生成工具制作；提示词保存在 [hero.prompt.txt](hero.prompt.txt)。插图用于说明“收任务 → 核对说明 → 交付归档”，不是界面截图，不展示真实客户材料。角色为本次封面根据文字规范生成的插画版本，不替代品牌的固定头像源文件。

界面由仓库的 Dataview / JavaScript 视图源码在隔离的虚构数据适配器中渲染，再对导出的界面 DOM 和项目样式进行浏览器截图。未使用生成模型重画产品界面。

画面中只有虚构客户、演示材料与手工填写的示例正文。为了让流程可读，示例预置了文件采用和周报候选；这些状态不代表真实客户项目、模型实测或本次已完成对外提交。运行环境、用户资料、会话记录及个人配置均不随截图发布。

新增的封面与界面截图随本项目按 MIT 许可提供。工作台本身仍使用蓝白界面，本轮只更新文档及其配图。
