首个公共版本：把日常售前工作中的消息、资料、任务执行与周报，串成可追溯的 Obsidian 工作流。

- 六分区工作台、五步收集与可编辑任务说明。
- 通过本机 Codex 开始和继续任务，保留来源、进度与成果位置。
- 文件用途分类、人工采用入口、交接导航与周报候选。
- 通用知识库骨架、虚构示例、安装冲突保护和可配置的本机命令。
- MIT 开源；不包含真实客户资料、个人设置和运行记录。

首版面向 macOS Obsidian 桌面端；需要 Dataview，AI 功能另需 Python 3.11+ 和已登录的 Codex CLI。Word 预览为可选功能。实验接口及验证范围请查看 README 和 docs/verification.md。
