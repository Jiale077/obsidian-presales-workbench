# 首版验证范围

首版发布前完成以下检查：

- Python 9 项测试：安装重入、同名冲突不写入、试运行不建目录、符号链接保护、设置合并与备份、默认不读会话历史、证据路径边界、采用文风片段与连续执行。
- Node.js 6 项测试：原稿与采用版本保护、并发修改后的撤销保护、路径边界、重复建档、周报候选与正文保护。
- 发布检查：Python / JavaScript / JSON 语法，凭据模式、个人路径和运行状态文件检查。
- 宿主渲染检查：Obsidian 1.15.0、Dataview 0.5.68，用隔离的虚构知识库适配器在 Dataview 环境中渲染六个分区，未发现视图执行错误。这个检查不等同于在全新安装环境中逐项完成所有交互。

持续执行测试使用模拟的 Codex app-server，验证创建、恢复同一会话、结果文件与执行记录，不调用真实模型。真实模型、云端转录、云端解析、Office 转换和不同 CLI 版本不包含在这组首版测试里。

仓库内 CI 会在 macOS 与 Linux 上重复离线测试；其实际结果以 GitHub Actions 页面为准，不把本机通过写成远程已经通过。
