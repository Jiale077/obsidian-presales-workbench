# 项目文件与接续规则

先读任务说明、项目索引、当前采用材料和既有接续入口。引用文件需要实际打开后才能依赖其内容。

既有文件保持原路径和名称。分类只维护入口，不移动附件；日期、文件名或修改时间不能自动决定采用版本。当前采用由使用者选择。

新任务默认位置：聊天截图放“聊天截图/”，来稿与录音放“原始资料/”，参考资料放“参考资料/”，正式成果放“交付物/”，需要保留的过程稿放“过程材料/”，脚本和临时文件放“work/”，交接放“会话交接/”。已有项目有约定时沿用既有位置。

累计交接写清背景、要求演变、已读资料、文件变化、验证范围和下一步。已存在固定交接时继续更新，保留历史。整理只维护工作台管理区，不覆盖区外业务记录。

完成情况必须依据实际文件与验证记录；生成初稿、结束一轮或手动归类不等于正式提交或客户验收。
