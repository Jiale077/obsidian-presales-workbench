# 工作台使用指南

打开 [[售前工作台]] 并切到阅读视图。需要启用 Dataview 的 JavaScript 查询与 presales-workbench CSS 代码片段。

## 从一项工作开始

1. 点“接一项工作”，填写标题、原始消息与背景。
2. 选择新任务、已有项目的新一轮工作，或给已有任务补充要求。
3. 加入截图、附件和录音，或搜索引用库内文件。外部材料保存为副本，库内材料只建立引用。
4. 可选“识别并进入核对”，让 Codex 整理说明；也可以手动填写。核对正文、来源和待确认信息后再采用。
5. 检查并建档，生成说明和项目索引。取消、关闭和暂存不会替代正式建档。

任务说明和附件是事实来源。识别稿可能有误，采用前应核对。未配置可选转录或文档读取工具时，可加入已有转录和 Markdown 正文。

## 执行与继续

在有 `说明.md` 的项目卡片点“开始 / 继续工作”。工作台使用本机 Codex CLI，每个任务保持独立会话。关闭面板不等于停止执行；需要停止时用“停止本轮”。成果默认写回任务下的 `交付物/`，执行记录保存在 `工作记录/`。

有真实问题或操作确认时，面板会等待你的答复。执行一轮不等于项目完成，项目状态需按实际情况更新。后台需要电脑保持运行。

不使用内置 AI 时，可复制任务说明到自己的工具。顶部“AI 协作面板”是可选的兼容插件入口，未安装不影响项目卡片执行。

## 项目和材料

“项目推进”支持星标、状态、阶段和下一步；缺少状态显示为未标注，不按文件日期猜测完成。

“整理文件”维护用途分类、当前采用与交接入口。采用版本由人工选择；整理不会移动既有文件。详细规则见 [[90-其他/工作台/项目文件与接续规则]]。

“材料库”按默认目录浏览；目录可逐层进入。Office 默认在外部打开，安装并启用可选预览插件后才会内嵌预览。

## 周报

首次进入“周报复盘”会收集本库文件线索，之后可手动刷新，用“＋”加入候选，选择归类和项目，再勾选生成初稿。修改时间只说明文件有变化，不能证明业务结果。

候选和正文可以手动修改；核对后再保存。已有同名周报会追加带日期的初稿区，不静默覆盖原文。文风规则见 [[90-其他/工作台/周报生成规则]]。示例范本可在 `weekly-report-style.json` 更换。

默认不读取 Codex 历史，也未安装定时刷新。可按 README 的配置说明主动开启对应选项。

## 倒计时与假期

在倒计时设置中修改下班时间，默认北京时间 18:00。假期使用公开公告日历，支持额外假期设置。断网使用已保存缓存，尚无公告的数据不会虚构连休安排。

## 保存位置

- 草稿：`00-Inbox/工作任务草稿/`
- 新任务：选择的业务目录下，包含 `说明.md` 与 `📂 索引.md`
- 正式成果：任务内 `交付物/`
- 后台状态：任务内 `.workbench/`
- 周报草稿与候选：`90-其他/工作台/.weekly/`
- 周报：`40-团队工作/工作汇报/周报/`

这些运行数据包含你的资料，不应提交到公共代码仓库。
